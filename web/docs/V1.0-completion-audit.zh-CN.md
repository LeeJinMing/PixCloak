## 尚不能由仓库单独完成

生产基线核验：2026-07-18 直接访问 `https://pixcloak.com`，域名、TLS、robots、两个 sitemap 与 `ads.txt` 正常响应；但线上 sitemap 仍公布 202 个 URL，`/safe-share`、`/upload-ready` 返回 404，且旧 Research、Benchmark、Case Studies、Templates、`/batch` 和语言页仍在线。新增的 `npm run audit:live` 会拒绝该旧部署，只有当前候选切流后满足冻结清单才会通过。

1. AdSense 站点已准备就绪、`ads.txt` 已授权、政策中心无问题，且已创建专用 slot `1345970286`。站点隐私消息由 Google Ad Manager 管理；账号恢复申请已经提交并处于 Google 审核中，审批通过后才能发布 EEA/英国/瑞士及美国州级消息。
2. 在上述 CMP 实际发布前，必须保持 `NEXT_PUBLIC_GOOGLE_CMP_READY=false`，Production 不得配置真实 slot 或开启广告。
3. 正式域名与 TLS 已在线，本候选已部署并通过 Preview 验收，但 `pixcloak.com` 当前仍运行旧版。仍需获得明确 Production 切流授权后创建 staged production build、配置生产环境变量和 IndexNow key、显式提升部署，并以 `npm run audit:live` 在真实域名复跑上线审计。
4. 灰度发布与回滚演练需要实际托管项目权限和上一稳定部署。
5. INP 是真实用户指标；本地交互延迟只能作为代理，必须等待生产 RUM/CrUX 数据后才能确认 `INP ≤ 200ms`。

因此当前形态可以作为“广告关闭的发布候选版”部署，但在上述外部事项完成前，不能宣称“合规广告版已经正式上线”。
