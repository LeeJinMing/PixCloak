PixCloak batch workflow sample

1. Extract the entire ZIP to one folder. Keep index.html, workflow.js and jszip.min.js together.
2. Open index.html in a recent Chrome or Edge browser.
3. Select "Try 3 generated samples" for a demonstration, or choose JPG, PNG or WebP files.
4. Set the maximum size, longest side and filename prefix, then process a batch.
5. Review the result table and download the verified images and report.

Files are processed locally. This sample does not send images or filenames to a server. Once downloaded, it needs no internet connection to process or export a batch. Visiting the service link opens the online PixCloak website.

Output: JPEG with white background; images are not enlarged. Output dimensions can shrink to meet the file limit. Size uses 1 KB = 1024 bytes. Only files that reopen and pass both selected limits enter the ZIP. Failed inputs appear in the report. Review visual quality and test one upload at your destination before using a whole batch.

Limits: 25 files, 20 MB per input, 100 MB total input, 30 million pixels per image. Corrupt and unsupported files are reported as failures. The sample is intended for recent desktop Chrome and Edge; other browsers have not been validated for this release.

The generated samples are artificial demonstrations, not client results. General tools and this sample are free. The paid service is configuration, verification and handover for an agreed set of requirements.
